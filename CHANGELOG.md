# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.2.0] - 2026-09-12

### Added
- LV-N Mk2 "Prometheus" Nuclear Thermal Engine
  - Liquid Fuel only propulsion - no Oxidizer required
  - Extreme vacuum specific impulse for efficient long-range and interplanetary burns
  - Built on the R.A.P.I.E.R. Mk2 airframe with a reactor-driven propulsion profile
  - Integrated alternator for onboard power generation

### Notes
- Best suited to vacuum and high-altitude operation; thrust and Isp drop off sharply in dense atmosphere
- Compatible with existing Filter Extensions and Community Category Kit integration

## [1.0.0] - 2024-09-12

### Added
- Initial release of KSP OP Engines Mod
- Overpowered variants of stock KSP engines:
  - CR-8.5 R.A.P.I.E.R. Mk2.5 (hybrid air-breathing/closed-cycle engine)
  - CR-8.5 R.A.P.I.E.R. Mk2 (hybrid air-breathing/closed-cycle engine)
  - LV-T30 "Reliant" Mk2 (enhanced liquid fuel engine)
  - Ion Engine Mk2 (enhanced ion thruster)
  - Turbo Ramjet Mk2 "Whiplash" (enhanced jet engine)
  - Mini Jet Mk2 (enhanced mini jet engine)
- Filter Extensions compatibility
- Community Category Kit support

### Features
- Significantly increased thrust values for sandbox play
- Optimized thrust curves for better performance
- Proper atmospheric and velocity curves
- Full gimbal control on all engines
- Enhanced effects and audio
- Balanced heat production and fuel consumption

### Dependencies
- Module Manager
- Community Category Kit (optional but recommended)
- Filter Extensions (optional but recommended)
